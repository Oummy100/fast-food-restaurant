# Fast Food Restaurant

Site web responsive pour un restaurant de restauration rapide, développé avec **HTML, CSS, Bootstrap et JavaScript**.

Ce projet est un projet de développement web frontend ayant pour objectif de créer une interface moderne, simple et responsive permettant aux utilisateurs de découvrir le restaurant, consulter son menu et réserver une table.

## Présentation du projet

Le site **Fast Food Restaurant** est composé de plusieurs pages permettant de présenter les différents services du restaurant :

- Page d'accueil
- Page Menu
- Page À propos
- Page Réserver une table

L'objectif principal du projet est de mettre en pratique les concepts fondamentaux du développement frontend et de créer une interface adaptée aux différents écrans.

## Fonctionnalités

### Accueil

La page d'accueil présente le restaurant et permet aux visiteurs d'accéder rapidement aux différentes sections du site.

### Menu

La page Menu permet aux utilisateurs de découvrir les différents plats proposés par le restaurant.

### À propos

Cette page présente des informations concernant le restaurant et son activité.

### Réserver une table

Une page dédiée à la réservation d'une table permettant à l'utilisateur de renseigner les informations nécessaires.

### Design responsive

Le site est conçu pour s'adapter aux différentes tailles d'écran :

- Ordinateur
- Téléphone
- Tablette

## Technologies utilisées

- **HTML5** — Structure des pages
- **CSS3** — Mise en forme et personnalisation
- **Bootstrap 5** — Système de grille et composants responsives
- **JavaScript** — Interactions et fonctionnalités dynamiques
- **Bootstrap Icons** — Icônes
- **Git & GitHub** — Gestion du code source
